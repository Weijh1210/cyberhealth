## 后端方案、成本与阻塞
沿用 Supabase PostgreSQL / Auth / RLS，邮箱 OTP 自愿登录，不改变游客体验。云端活动使用 `(user_id,event_id)` 唯一键，只导入用户同意的真实完成记录；偏好用乐观版本号检测冲突，让用户明确选本地或云端。不同账号在本机使用不同存储键，退出恢复游客仓库。导入失败不清除本地数据。

[官方价格](https://supabase.com/pricing)（本轮核对）：Free $0/月，500 MB 数据库、50k MAU、5 GB egress；不活跃 1 周会暂停。Pro 从 $25/月起，可有计算/流量等额外费用。本轮不开通付费服务。邮箱投递的测试限制与正式 SMTP 配置需在测试项目验证，不把 SDK 请求成功当作实际送达。

阻塞：没有测试项目环境变量、没有批准执行的数据库迁移。允许准备代码与 SQL 草案，**不执行远程迁移、不创建服务、不声称两真实账号验收通过**。用户需配置 `.env.local`（仅 publishable/anon key，不用 service role）、启用邮箱 OTP、按审核后的迁移步骤建立测试数据库，再联调。
