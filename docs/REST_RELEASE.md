# 新版休息助手验收记录

- 桌面主区域宽度 1100px，手机使用全宽单列和固定底部导航。建议和主操作始终排在插画前。手机 390×844 实测默认主按钮在首屏内。
- Chrome 三档检查（1440、768、390px）对比：旧版首屏 1 个 Canvas，手机有小于 11px 的控件文本；旧版移动视口部分文字对比度为 2.8:1 和 3.3:1。新版首屏无 Canvas，检查未报小字号或低对比文字。新版正文用系统中文字体，标题用宋体；设计检查的 Instrument Sans 例外是为了使用完整中文字体并支持离线。
- 内容核对：交节资料来自香港天文台 2025–2028 年官方 XML；紫苏叶与陈皮形态分别核对香港浸会大学 B00338、B00162；方剂参照该校 F00147 所录《太平惠民和剂局方》，姜枣按其用法说明与主方组成分列。App 内提供馆藏直链和校方图书馆目录；验收时个别直链请求返回 HTTP 503，可从目录按记录编号检索。插画均为仓库原创 SVG，未复制数据库照片或页面图像。
- 天气验收：杭州 Open-Meteo 真实响应及本机 Chrome 页面均已核对；浏览器显示 11 月 11 日 03:30（杭州当地时间）的天气与来源。测试另覆盖交节前后、城市昼夜、晴雨、失败缓存、无缓存和减少动效。
- 触达：站内提示、分项处理和提醒直达建议已做浏览器验收。系统通知依赖实际授权、浏览器与操作系统调度；后台与关闭 App 不承诺准点送达。

- 草木册新增虚拟紫苏小圃：浇水当天有土色、叶片和文字反馈；累计在两个不同日期照料即可压叶收藏。旧种植记录可以直接继续照料。动作库共有 16 个来源核对动作，其中新增手指开合、翻掌、坐姿脚跟脚尖轮换和双肩轻绕。
- 四时纸笺界面：手机保留首屏休息操作；签筒在手动抽取或晃动时先晃、再出签，揭签后保留既有同日记录。动作感应需支持 DeviceMotion 的安全页面；Chrome 自动化使用模拟传感器输入，未在实体手机上验证。草木册支持单页翻阅与全册展开，种植和翻页尊重减少动效设置。
- 参考用户提供的自然疗愈 App 图稿，更新为浅绿底色、白色圆角卡片、绿色景色与原创叶芽伙伴；手记展示实际记录数量，标本册保留单页与展开阅读。抽签、种植、提醒和本地迁移路径继续沿用。
