# CyberHealth（摸鱼养生局）

「节气百草局」把工间休息和一座临水本草院连起来。打开首页就能开始当前推荐，也能抽节气签、种紫苏和引水。

## 本地运行

使用 Node.js 20.19+（若使用 22.x，请用 22.13+）。

```sh
npm ci
npm run dev
# http://127.0.0.1:4173
```

### 最短试玩路径

1. 点击木案上的「歇一下」，开始计时。计时结束后确认完成，一株紫苏苗会放入药篓。
2. 点「回院种紫苏」，点药篓，再点空着的窗边或水渠旁。桌面也可把药篓中的苗拖到种植位。每次完成一项指导活动可得一株苗。
3. 点「扳竹槽」，分别试「引向陶缸」和「引向药圃」。缸里会逐格加水，浅渠会把水导到药圃并润湿土面。晴天也可用院中存雨试水路。
4. 点竹签筒抽一支，先看编号，再翻看签文和资料。雨天可抽到「借雨」。当日签保留抽取时的天气与节气，刷新或天气变化后仍可翻看。
5. 翻看紫苏叶并制成标本页。转动陈皮并收存后，在「手记」选取标本，把它们分别放到香苏散的君药和佐药位置。

活动筛选沿用可用时间、姿势、场景、空间、安静程度与现场支撑。需要扶墙或稳固椅子的动作仍会在开始前确认。木门、竹帘和「其他休息」也提供可直接放下设备的短休息，记录自愿。

## 院落与资料

- 院落、角色、标本和环境声由仓库代码生成。透视 Canvas 场景中的坐标也用于定位可点按物件。系统减少动态效果时保持静态视图，Canvas 不可用时用 SVG 保留等效操作。院声默认关闭。
- 节气按北京时间日期匹配 [香港天文台历表](https://www.hko.gov.hk/en/gts/astronomy/Solar_Term.htm)，现有数据覆盖 2025–2027 年。晨昏光线按设备本地时间变化。
- 天气按手动选择的城市从 [Open-Meteo 当前天气](https://open-meteo.com/en/docs)读取，显示数据时间。接口暂时不可用时仍可开始休息、抽基础签和试水路。
- 依据可在签背与图谱中查看。标本资料参考香港浸会大学的[紫苏叶](https://sys01.lib.hkbu.edu.hk/cmed/mmid/detail.php?pid=B00338)与[陈皮](https://sys01.lib.hkbu.edu.hk/cmed/mmid/detail.php?pid=B00162)。[香苏散历史图谱](https://sys01.lib.hkbu.edu.hk/cmed/cmfid/detail.php?id=F00004&lang=chs)依据《太平惠民和剂局方》，用于历史展陈。药童只对下巴微收与肩胛轻夹提供简化姿势示意，动作细节以既有文字卡为准。

## 提醒与本地数据

- 「我的节奏」保留休息提醒的间隔、工作时段、免打扰、每日上限、暂停、延后和跳过。休息提醒可以直接进入推荐动作。
- 生活提醒可选喝水或自定义事项，按本机时间每天在前台触发。同一时刻到期的事项与休息提醒可在同一张提示里查看。休息提醒支持主动授权浏览器通知。后台或休眠期间可能延迟，关闭页面后停止调度。
- 沿用 `moyu-wellness-v1` 和既有数据迁移。历史动作、偏好与旧游历保留。新庭院进度、标本和生活提醒保存在当前浏览器与同一个访问地址下，可导出 JSON 或经确认清除。已有可选账号入口仍在「我的节奏」。云端配置见 [Supabase 设置](docs/SUPABASE_SETUP.md)。

## 验证

```sh
npm test
npm run typecheck
npm run lint
npm run build
npx playwright install chromium
npm run test:e2e
```

E2E 使用生产服务器，包含桌面 1440×1000 与手机 390×844 触控视口。可用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定 Chrome，或用 `PLAYWRIGHT_PORT` 避开运行中的预览。庭院截图输出到 `test-results/`。开发模式跳过 Service Worker，体验安装或离线请用 `npm run build && npm run start`。
