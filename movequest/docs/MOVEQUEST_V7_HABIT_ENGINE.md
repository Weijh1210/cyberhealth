# MoveQuest V7.0 · 习惯引擎

一次发现可展开行动记录。用户主动确认完成、选填便利度，或跳过并选填原因。跳过不解锁街区。做过一次后可以把对应场景、线索和动作存成习惯。以后从习惯花园记录触发后的新尝试，自行勾选是不是本来就记得做。

同一计划的重复以本地日期计算。阶段依次参考是否尝试、跨日重复、便利度以及自报主动发起。一次自主发起只展示「主动发起过」。没有断签惩罚。多次主动完成时，开启过前台提醒的用户可进入偏好降低频率。

跳过针对当前线索提供短冷却。根据太累、社交不便、时机不对等选项，习惯卡给出不同的下次调整建议，排序主要影响同一地点与相关子类型。适应建议由本地规则产生，反馈不触发模型请求。

可开启 3、5 或 7 天的单计划实验。假设是同一个触发方式是否方便，结果来自时间窗内的记录和便利度回答。当前只保留每个计划最近一轮实验，不做 A/B 自动比较或任何临床结论。演示里的「加载模拟习惯记录」只在示例计划可用，历史在演示状态中。个人记录在同一浏览器持久化，支持现有备份导出。
