# MoveQuest V4 — 五分钟演示稿

预演入口：`http://127.0.0.1:5176/demo`。演示空间独立保存，可重置；个人世界、资料与记录保留。下面的示例资料不是用户真实活动或定位。

## 演示前（不计入五分钟）

1. `cd movequest`，`npm run build`，`npm run serve`。确认页面有最新版；如果提示更新，先结束计时再点击“更新应用”。
2. 在本机 `.env` 配置 `OPENROUTER_API_KEY`；不要展示文件或 Key。默认 Dots 免费模型已做真实中文、英文与纠错测试，免费服务仍可能限流。
3. 打开 `/demo`，点击“载入示例演示世界”。先确认“会议刚结束”情境有活动。可以先关闭离线安装提示，减少占屏。
4. 提前核验麦克风权限。浏览器识别不支持时使用文字，不临时安装付费 ASR。桌面推荐 1440×900，手机已做模拟视口验证。

## 0:00–1:00 — 一句话认识生活

讲：“MoveQuest 把我的生活节奏变成自己的世界。AI 只负责理解描述。”

从“生活发现”进入，或打开 `/life?example=1`。输入／语音转写后先检查文字，再点“让 AI 理解我的一天”。可用示例：

> 工作日早上8点在我的小屋起床，8点30分到绿荫地铁站乘地铁，9点到日光工作室上班，上午10点到10点30分开会，12点30分到13点在午间食堂吃午饭，18点下班后回家。

展示时间、地点、工作日和待澄清问题。强调未知时间留空，大约时间有标记，资料确认前不写入世界。不展示 API Key 或调试 JSON。

免费模型限流时，直接说明“在线理解暂不可用”；回 `/demo` 用“载入示例演示世界”继续。明确这是预置样例，不能称为本次实时 AI 成功。

## 1:00–2:00 — 世界诞生

确认资料进入城镇，或回到独立示例世界。

讲：“建筑代表生活场景，不是实际 GPS 地址。地图和道路由算法生成，不消耗模型调用。”

选择我的小屋、日光工作室、社区书院或地铁站，演示相机聚焦、缩放、平移和重置视角。切换日光／暮色主题。指出道路、街边绿化、建筑入口与不同建筑结构。装饰车辆只是游戏环境，不能代表用户真实移动。

## 2:00–3:00 — 从事件找到间隙

选择“日光工作室”场景。

- “准备接水”：展示接水走动。
- “午饭刚结束”：展示饭后短走。
- “会议中／忙碌”：展示没有推荐。
- “会议刚结束”：展示工作间隙与休息候选，展开“为什么推荐”。

强调顶部“演示模拟，非实时监测”。点“查看活动”，展示说明、开始／暂停／明确确认。演示模式计时缩短，奖励和记录单独保存。

引导微动作可在“引导微动 · 审核状态示例”查看：尚未经过专业审核，因此没有开始入口。不要把待审核动作演成已审核活动。可执行的是一般自然活动、休息及自然活动组合。

## 3:00–4:00 — 反馈真正改变排序

回到接水情境，选“不适合的原因：对这类活动没兴趣”，点击“不适合我”。展示该活动的分数下降；再切到“午饭刚结束”，饭后走动仍可推荐。

讲：“系统记录具体活动和子类型。现在太忙只触发临时暂停，对接水走动没兴趣也不会消灭所有自然活动。”

选择“希望更短一点”展示时长偏好；可以进入“节奏与反馈”核对记录和重置排除。不要宣称这是训练了大模型或测量了健康改善。

## 4:00–5:00 — 新生活让世界生长

回 `/demo` 点击“确认周末公园示例并扩展”，或在生活发现中手动／AI 补充周末公园，检查并确认。

展示新公园、发现手记与旧建筑位置保留。选择建筑，放置喷泉／路灯／花箱等；点击装饰后移动、删除、撤销。手机点击“查看活动机会”打开底部详情，并收起后编辑装饰。

最后回 `/demo` 点击“退出演示，回到个人空间”，证明个人世界保留。用一句话结束：“让活动顺着生活发生，也让生活在自己的世界里被看见。”

## 问答口径

- 数据当前保存在浏览器，支持 JSON 导出与校验后确认导入；没有跨设备自动同步。
- 活动为用户自报确认；休息和包含休息的组合会话不计为运动分钟，没有设备测量或健康效果承诺。
- 所有 AI 调用受免费白名单和零价格上限约束；现有 Key 继续使用，不自动调用付费模型。
- Plus 仍是明确标注的方案和意向收集，不是已上线付费订阅；机构页仍是 Demo Data。
