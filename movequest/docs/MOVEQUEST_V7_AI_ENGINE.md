# MoveQuest V7.0 · AI 与生活上下文

继续使用同源 `/api/life/extract`。单次调用返回地点、事件、偏好、限制、候选行为线索和有关原话。多轮对话会把当前草稿里需要保持的标识传给模型，前端合并每轮变更。语音在浏览器转成可编辑文本，发送由用户触发。

- 行为线索包括刷手机间隙、视频结束、任务完成、会议后、下课、既有接水、办事、通勤到站和饭后。模型选行为类型并提供逐字证据，内置动作目录生成执行细节。
- 地点和日程沿用原来的稳定 ID。新线索和事实包含稳定 ID、来源、事实证据、置信状态、场景关系，并在确认时记录更新时间。事件的日程时间可空。
- 服务端限制字段、长度、枚举和模型。无原文或无场景关系的 AI 线索不会进入草稿。确认后才可能生成可执行机会，明确不确定的线索仅供核对。用户可继续对话纠正，可以手动补充线索，也可在确认编辑中移除错误项。
- 目录匹配取决于场景及线索类型。系统检查活动审核状态、时间预算、走动和站立限制。确定性评分使用触发具体度、低摩擦偏好、是否已尝试和场景内反馈；语义去重采用场景、时长和子类型，不计算向量相似度。长期偏好尚未拟合。
- 同一行为证据不意味着真实设施或某条路线存在。实际空间、路线和可达性仍由使用者检查。

默认使用已验收的 Dots 免费模型和既有免费候选白名单，最多尝试两个候选。上游价格上限为零，关闭提供商跨模型回退。密钥仅在服务端环境，缓存或状态响应不暴露密钥。普通单元和浏览器测试不调用模型。真实验收的样例均为虚构。

当前事实图谱是本机地点、事件、线索和事实表中的关联，未实现完整的任务依赖和通用图形编辑器。事实的更正依赖多轮、显式确认和移除，新 ID 的同名同类地点会并到旧地块，相关引用一并迁移，严格重复事件会去重。异名实体仍需手动核对。自由文本条件不能代替逐项许可。模型有可能漏掉明确行为或标错行为类型。
