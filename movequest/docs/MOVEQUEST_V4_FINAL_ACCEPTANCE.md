# MoveQuest V4.0 — 演示交付与验收

日期：2026-11-23，Asia/Hong_Kong。本次在已有 React/Vite MoveQuest 内迭代，根 Next.js 应用未替换。安全检查点在忽略的 `.checkpoints/before-v4-*.tar.gz`，不包含 `.env`、私有服务端账本或签名密钥。没有提交、推送、部署或发起付款。

## 启动与演示

```sh
cd movequest
npm run build
npm run serve
```

完整本机应用与 API：`http://127.0.0.1:5176`，演示入口 `/demo`。服务需保持运行。开发时 Vite 5174 代理同一 5176 API；仅静态 preview 不代表 AI 后端可用。

演示稿见 [MOVEQUEST_V4_DEMO_SCRIPT.md](MOVEQUEST_V4_DEMO_SCRIPT.md)。所有演示操作经过现有 reducer、存储事务、地图布局和推荐引擎。预载示例明确标注，不冒充 AI 响应；重置演示不清除个人资料或完成记录。

## 已实现与验证

| 范围 | 实现与实际边界 |
| --- | --- |
| 免费 AI | 6 个明确的 :free 白名单；首选真实通过测试的 Dots。每次输入最多尝试两个不同免费候选，总超时 45 秒。零价格上限、无未知模型／付费回退；账户配额或认证失败停止 |
| 真实理解 | 基础中文 3 组、扩展中英 6 组、稳定 ID 增量纠错 1 组的关键断言通过；成功响应的 usage.cost 均为 0。另用真实浏览器输入虚构日程，调用同源后端、确认结果并生成 5 个可选择地点。不是统计学准确率或全部自然语言保证 |
| 确认与限制 | 待确认表单可改地点、时间、工作日／周末、交通和忙碌；大约时间保留 approximate。显式站立／走动限制在确认后进入 eligibility；不推断医疗诊断 |
| 地图 | 原创等距实体几何；住宅、办公室、书院、地铁和公园有不同结构。新增绿化空地、中央景观、道路入口连接、路灯／喷泉、环境小车、树叶动画与两个主题。参考图的高精度材质／室内剖面仍未实现 |
| 几何布局 | `worldLayout.ts` 与美术分离，按住宅／工作／交通／绿地区锚点和 seed 分配空地；保留所有已有坐标。固定 footprint 与入口、共用路网栅格；单元测试验证新地块与街道主干避开建筑占地。不是实际道路导航 |
| 相机交互 | 拖动、双指、按钮与键盘平移缩放；平滑选中聚焦和 fit 重置；新增节点入场。手机机会详情使用可收起底部面板；减少动画偏好关闭装饰动效 |
| 世界成长 | 新地点确认、新建筑与六个新装饰槽、发现手记；树、花丛、长椅、路灯、喷泉、花箱六类，可放置、选择、移动、删除、撤销，支持持久化与主题恢复 |
| 事件机会 | 接水、电话、会议结束、午饭后、桌前、转换、闲暇和忙碌情境。按确认日程推测时明确不是实时观察；手动事件来自用户确认。演示情境明确标“模拟”。忙碌允许无推荐 |
| 内容库 | 35 条：15 个自然活动、10 个休息、3 个自然活动组合、7 个待专业审核的引导动作。场景／触发条件／时长／设备与空间／走站要求／来源／审核日期和核对口径随记录可查。没有伪造临床或专业审核 |
| 三层架构 | Level 1 自然活动与 Level 3 自选自然活动组合可执行；Level 2 引导动作仍因未专业审核而阻止推荐和开始。这是明确的外部依赖，不是三个层级全部上线 |
| 细分学习 | 按活动、子类型、时段、场景与较短时长的原因更新。单项与子类型权重有上限、按时间衰减；不再对所有 natural 做广泛惩罚。太忙／做过／时间或地点不对以临时暂停处理。理由与评分展示、反馈记录可核对 |
| 语音 | 浏览器 SpeechRecognition／webkitSpeechRecognition，中英切换、开始停止、错误与权限状态、可编辑转写；不自动提交 AI，不将原音频发给文本模型，也不保存录音。不支持时手动输入。自动化转写使用明确的浏览器 API mock；实体麦克风与各浏览器服务未做实录验收 |
| 资料隔离 | demoLife 和 demoProfile 独立；个人活动、奖励保留。JSON 导出保留完整快照，导入先校验并要求确认替换；未知版本／损坏数据不静默覆盖 |
| 统计诚实 | 开始不等于完成；休息不计运动分钟。含休息的自然活动组合也独立，不把全部会话时长记作运动分钟。没有虚构真实用户健康进展、留存或收入 |

## 剩余限制

1. 引导动作需要真实专业内容审核；演示只展示待审核，不伪造 Level 2 可执行性。
2. 免费端点可能限流。前端可以手动录入或明确载入演示，不会自动伪造 AI 成功。
3. 微缩地图仍是矢量实体几何，不是参考图级 3D 美术。没有室内剖面、天气系统、复杂人物或真实 GPS。
4. 语音实际服务依赖浏览器，部分浏览器可能将音频交由自身远程识别服务；未引入付费 ASR。尚未验证实体手机和实录识别准确率。
5. 日程仍以 daily／weekday／weekend 为主，不是完整日历或排班系统；不规律／矛盾内容保留问题，需用户确认。
6. 没有账号与跨设备同步、后台推送、支付订阅或生产部署。服务端仍是单进程私有文件账本，公开上线需要部署与隐私处理流程。
7. 40 地点上限有布局测试；没有实体手机极限 GPU 帧率或正式人工无障碍认证。
