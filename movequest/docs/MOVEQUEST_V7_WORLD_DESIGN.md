# MoveQuest V7.0 · 城镇与成长

城镇继续使用现有 SVG 等距投影，住宅、公司、学校、地铁、食堂和公园保留。新增原创图书馆外观，延用青绿色屋顶、浅色书窗及门前花箱。透明度、暖色路面和植物沿用已交付主题。继续复用当前绘图系统，无新增渲染依赖或游戏资产。

确认地点时由固定 seed 和分区规则计算新地块。刷新与补充场景不改旧坐标。发现用叶芽标记，选择建筑可探索，地图保留平移、缩放和可移动装饰。

首次确认尝试后，关联地块出现「新芽步道」。第二次加灯笼，第三次加开花的树。「探索图鉴」会同步展示该地块的最高装饰层级。试做、点击、跳过和模型推断均不会解锁装饰。这些变化只表示玩家确认了体验。示例模式下的解锁属于示例空间。

当前成长集中在地块及地面的可见装饰，没有改变建筑体量的升级、复杂居民行为、室内场景或剧情伴侣。保留可用的原始造型更有利于接入既有稳定世界坐标。
