## 浏览器实测覆盖

以下 13 个用例分别在桌面和手机执行，共 26 项：

1. Onboarding 选择、空场景校验、保存与刷新保留。
2. 计时开始/暂停/继续 → 明确确认 → +20 XP → 知识错答与重试 → +5 XP → 成长记录 → 演示/个人空间隔离。
3. 同一天重复完成同一任务、本次 +0 XP；连续触发确认不会重复发奖。
4. 步骤按序完成、跳过、重新开始、替换任务，不扣分。
5. Create Your Own Move 保存、自建挑战、成长发现列表与刷新保留。
6. 两个标签页同时确认同一个任务，只生成一条完成记录与一次奖励。
7. 机构类型/周期筛选、草稿新建/修改、刷新保留、导出内容持续标注 Demo Data。
8. 生产 service worker 控制页面后断网，深链进入探索与挑战、完成步骤活动、刷新、查看进度。
9. 八个主要页面无运行时 pageerror、无水平溢出，自动无障碍检查通过；补查 320 / 768 / 1440 宽度。
10. 损坏的本地数据保持原样，可导出原始内容，不静默覆盖。
11. 正式一分钟任务刷新后不把离开时间计入活动，接续后可完成并记录 1.0 分钟。
12. 偏好修改、英文导航与中文回退、主要导航逐项点击、JSON 导出、清除取消/确认；旧应用测试键保留。
13. 前台提醒可关闭，PWA manifest、图标与 maskable 图标资源可访问。

单元测试另覆盖新用户零记录、奖励日期边界、知识奖励去重、不同自建活动共享每日奖励上限、存储失败/未知版本、机构分项与总量一致等。

测试使用隔离浏览器上下文与受控时钟，不等待真实一分钟或半小时。正常模式计时用例中的活动是自动化测试输入，不作为用户真实运动成果展示。交付截图使用明确标注的演示空间或机构 Demo。

## 已修复的可复现问题

- 异步持久化尚未完成时展示结果，可能让紧接的整页刷新读到旧数据：完成/学习/编辑结果改为事务成功后显示，模式开关保留即时反馈与保存状态。
- 次级文字在浅色知识入口上的对比度不足：加深文字颜色，重新执行 axe 检查。
- 手机知识卡横向列表撑宽 Grid 子项，移动布局视口扩大、底部导航点击偏移：约束 Grid 子项最小宽度为 0，滚动限制在知识卡列表容器内；溢出断言对照 clientWidth。
- Vercel SPA 回退正则转义过多：修正并加入测试，保证页面深链回退而 service worker、manifest、图标、脚本与许可资源不被回退为 HTML。

## 已知限制与未验收范围

- 繁中/英文仅完成导航预览，活动与学习内容回退简中。
- 没有真实设备或步数检测、账号/云同步、JSON 导入、后台 Push、多租户权限或真实机构接入。
- 机构指标是固定合成数据，本地活动草稿不会改变 KPI；没有真实客户或试点成果。
- 缺少 Web Locks 的浏览器不保证多标签页同时写入的一致性；localStorage 不提供防人工篡改能力。
- PWA 离线需先成功联网缓存；实体 iOS/Android 安装、系统通知、跨浏览器和真实线上版本升级未进行验收。
- 自动无障碍规则通过不等于完整人工认证。设计 inspector 的四项样式警告有记录，未伪称全部设计探针无警告。
- 活动时长是产品体验参数，步骤活动时长为自报估计；没有进行医学效果或真实行为改变研究。
- 数据受当前浏览器/协议/主机/端口约束；隐私模式、清理浏览器或换设备可能失去本地记录。

原 CyberHealth 业务源码、数据键和依赖未改动。根 README 仅增加 MoveQuest 入口；既有 `deliverables/` 未触碰。
