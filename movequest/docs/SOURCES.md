# 内容与素材来源

核验日期：2026-11-19。健康内容只作一般活动教育，任务时长和 XP 是产品设计，不是经过医学验证的剂量，也不用于证明特定效果。

| 知识卡 | 来源 | 用途与边界 |
| --- | --- | --- |
| 身体活动，藏在日常里 | [WHO Physical activity](https://www.who.int/news-room/fact-sheets/detail/physical-activity) | 概述身体活动包含主动出行、工作与家务等日常活动 |
| 从一点点开始 | [WHO Physical activity](https://www.who.int/news-room/fact-sheets/detail/physical-activity) | 概述少量活动优于完全不活动的原则，不承诺个体效果 |
| 坐着，也有轻动的选择 | [NHS Sitting exercises](https://www.nhs.uk/live-well/exercise/sitting-exercises/) | 稳固无轮座椅、脚部支撑、循序渐进的原则；不是康复处方 |
| 把步行放进生活 | [NHS Walking for health](https://www.nhs.uk/live-well/exercise/walking-for-health/) | 从短距离开始、融入日常；本应用不声称 1–3 分钟即满足活动指南 |

任务是独立撰写的生活机会示例。走路时收起手机、远离车流热源和障碍、可随时停止等提示属于产品使用的安全设计。不会要求用户完成专项康复、忍痛活动、追逐计时或达到指定心率。

美术：花园、植物、场景与应用图标为本项目用 SVG/CSS 独立绘制；图标 PNG 从项目自绘 SVG 渲染。没有复制四个候选仓库的源码、图像、音乐、字体或品牌素材，没有使用生成照片或外部 CDN 字体。

UI 线性图标使用 Lucide React，遵守其 ISC 许可证。系统字体由用户设备提供。

机构数据见 `src/data/institution.ts`：60 个合成参与者，校园 36、企业 24；静态快照为 2026-11-19。任务明细与学习状态由确定性规则生成，无真实身份。所有 KPI、场景分项和每日图表从这些明细推导。截图中“青禾”是隔离浏览器测试姓名，不是真实用户成果。

开源调研与技术选择见 Phase 1；公开仓库不自动代表素材获授权。StepsNSprouts 未确认许可证，因此没有复制其实现或资源。
