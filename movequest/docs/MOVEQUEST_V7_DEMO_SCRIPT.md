# MoveQuest V7.0 · 约六分钟演示

1. **0:00–1:15 · 描述日常。** 打开 [本机演示](http://127.0.0.1:5176/demo)，点「从真实 AI 对话开始」。检查文字后发送。核对图书馆、刷手机间隙和行动偏好。选「确认资料并生成城镇」。免费模型暂时不可用时回到演示入口，选「载入 V7 示例（无需 AI）」，明确告诉观众此处是示例。
2. **1:15–2:15 · 找到一次可试的转换。** 看「写累了就刷手机」那张发现卡，讲清可以只换掉其中一次，而原来的休息方式也可以保留。展开「为什么值得试」，展示世卫组织链接和局限。
3. **2:15–3:15 · 尝试并确认。** 点「试一次」。演示行动由演讲者自愿模拟。可选便利度，再点「我做过了，确认记录」。在结果卡将这个时机种成习惯。
4. **3:15–4:20 · 城镇回应。** 点「查看街区变化」。在图书馆前指出浅金色步道和花丛。缩放、选地点或打开探索图鉴，展示解锁。提醒观众这是体验记录的奖励。
5. **4:20–5:10 · 一次不合适的机会也有用。** 回到今日发现，点「这个机会不适合」，选择「这个场合不自在」，记录后查看其他场景如何保留。当前被拒绝的会暂时退出推荐。
6. **5:10–6:15 · 从尝试到习惯。** 打开习惯花园，记一次尝试并选是否主动想起来。展开三天实验，显示真实记录的计数。若要展示后续变化，在无需 AI 示例创建习惯后，点击「加载模拟习惯记录」并明确标为模拟。
