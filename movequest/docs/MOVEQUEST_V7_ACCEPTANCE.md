# MoveQuest V7.0 · 实现与验收

本机预览 [http://127.0.0.1:5176/demo](http://127.0.0.1:5176/demo)。也可进入 `movequest`，运行 `npm run build` 与 `npm run serve`。基于原 React/Vite 项目实现，导出格式保留向后兼容的版本号。源码检查点存放在 Git 忽略的 `.checkpoints/before-v7-*.tar.gz`，排除了密钥、账本和本地用户资料。

## 已实现并实际验证

- 在多轮 AI 生活对话里识别行为线索和带原话的事实。确认前可检查，原先的日程编辑、语音转写、手工录入和地图保持可用。
- 模型选择行为线索，代码映射到有审核状态的活动，并过滤行动限制、去重、执行短冷却。发现卡提供原话、触发、时长、行动、适用条件和经核实的 WHO 指南。
- 在桌面和手机演示中试一次、确认、解锁步道、创建习惯、记录便利度与主动完成、开启实验、刷新复查并用「这个场合不自在」跳过。跳过后仍有其他发现。
- 确认生活场景生成稳定地块，新增图书馆建筑、发现标记、步道和分级装饰，探索图鉴显示解锁。演示、个人状态隔离。旧版带计时的挑战、扩区、装饰移动、备份、离线应用仍有回归覆盖。
- 五个主导航区域与手动备选入口已接入。交互分析记录只保存本机，当前未产生真实留存指标。

## 真实免费模型验证

最终复测用五条虚构描述，实际成功响应均来自 `dots-studio/dots-3-note-preview:free`，各次估算费用均为 **0**。学生场景实际从网页提交并确认，随后在真实浏览器中完成模拟尝试、创建习惯、检查新步道。其他四条从本机后端调用，使用同一推荐函数验证输出。

| 场景 | 识别证据 | 应用结果 |
| --- | --- | --- |
| 学生 | 「写累了就刷手机」「晚上回家躺在床上看视频」等，少出汗偏好 | 图书馆刷屏间隙、家中视频转换等不同发现。学习时长不等于已知坐了多久，久坐事实标为不确定 |
| 办公 | 「工作日早上在青禾公司开例会」「每次保存报告才会停一下」 | 办公任务转换，同一短步行的变体合并 |
| 远程工作 | “after finishing each block of coding”，空间有限 | 在家任务收尾，短步行仅在本人确认路线安全且可达时尝试 |
| 通勤 | 「坐地铁到松林站，下车后沿熟悉的路走到教室」 | 到站后利用本来就要走的一段，未生成虚构街道或设施。初轮更短描述漏掉了线索 |
| 不喜欢运动，有明确限制 | 「晚饭后我在家看视频」，不愿走与站 | 保留视频线索，实际输出 0 条可执行走动机会 |

普通测试使用固定自报数据或模型端点 mock。硬性限制由本地确定性逻辑执行。实测覆盖这五组，不代表总体识别率或免费端点可用性承诺。

## 构建与浏览器检查

- TypeScript、ESLint、客户端 Prettier 检查与生产构建通过。10 个单元和集成测试文件、67 项通过。
- 完整桌面和手机回归共 42 项通过。地图最终区分即时活动和生活发现后，V4/V7 两组共 10 项再次通过。
- 查看桌面和手机的地图、手机发现与习惯截图，并检查 1440、768、390 像素的演示布局。检查器没有失败，保留一条既有浅暖色按钮的视觉提示。端到端新增用例对发现与习惯卡执行了 axe 检查。
- 后端实际密钥值在生产前端文件中未检出，Git 忽略 `.env` 与检查点目录。

## 范围与风险

| 状态 | 范围 |
| --- | --- |
| 部分实现 | 上下文以关系记录和固定线索集合为主，合并依赖稳定 ID 或同名同类匹配，别名合并需手动核对。机会质量用透明规则，尚无通用语义检索、对比实验分析、完全自动的多理由画像或者持续成熟度预测 |
| 部分实现 | 五级原有 XP 展示仍在历史页面，V7 首次引导与主要世界成长由真实确认驱动。三层活动保留，Level 2 未获专业审核，不能执行。证据仓库从一个已核实的一般性条目开始 |
| 未实现 | 专业动作审核、实景身体检测、背景提醒、跨设备同步、付款、独立伴侣、建筑体量升级、深入居民系统或参考图级资产 |
| 模拟 | 演示入口明确分开真实 AI 与无需 AI 示例。模拟尝试、预设世界、模拟后续历史仅在演示空间，实例截图不代表用户健康结果 |
| 技术风险 | 免费服务限流、模型漏提、浏览器语音依赖支持与权限，长期本机记录需备份；分析窗口有限。物理麦克风与真实手机实录未验收 |
| 产品风险 | 还没有长期使用、行为改善、复访或付费意愿证据。低摩擦和真实便利度需继续以用户自报验证 |
