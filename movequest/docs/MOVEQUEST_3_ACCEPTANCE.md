## 已实现链路

- `/onboarding` / `/life`：生活描述、服务可用性检查、真实模型请求或手动表单；地点/事件/时间/重复/到达方式/忙碌字段可编辑；增量合并与全量编辑分开，确认后更新世界。移除地点级联移除关联，已有其他坐标保留。
- `/`：程序化微缩城镇，建筑/道路可选择，拖动平移、双指与按钮缩放、键盘方向键与加减缩放、动态机会标记、免费三种装饰与三个位置槽。地图之外的成长记录保留在可展开区域。
- 本地日程时间轴使用配置的 IANA 时区。点事件、未知结束时间不会自动变成整天窗口；不推测真实定位或连续久坐。手动场景选择代表主动空闲窗口，仍服从静默与明确限制。
- `/rhythm`：静默、走动/站立、每日接受上限、时区、推荐开关；展示数、反馈数、拒绝数、自报休息完成；反馈历史、排除重置、逐项活动审核详情。
- 活动库有 **18 条**，其中 **9 条一般自然活动、6 条休息可用，3 条引导动作待专业审核**。全部有场景、时长、说明、设备、场地、限制、来源口径和审核元数据。没有为凑 30–40 条虚构专业审核。引导动作从自动推荐、探索入口及 reducer 直接开始入口排除。坐姿引导替代不再对新活动开放。
- 活动开始与明确确认完成分别记录。休息可获 5 XP，但不进入运动次数/分钟；自然活动延续原 20 XP 及每日防重复奖励。演示数据始终与个人数据分离。
- `/plus`：真实登记邮箱意向的 HTTP 服务与私有文件持久化、同邮箱去重、明确同意版本；无后端时仅保存本机价格意向并明确告知不会收到联系。不伪造支付、会员权益、收入或订单。当前 Plus 权益只是方案，所有用户是 Free。价格由已持久化 seed 的固定桶选择，默认 seed 为固定值，**没有完成随机 A/B 分流或商业实验**。

## AI 与服务端

`server/index.ts` 是单进程 Node app/API 服务，也可直接提供构建后的 SPA。`server/ai.ts` 支持配置完整 Chat Completions 兼容 HTTP endpoint，不锁定供应商。

- 密钥只从服务端环境读取；不使用 `VITE_` 密钥，不在静态包内包含 Key。
- 输入最多 4000 字，HTTP 请求最多 24 KB；输出最多 2400 token，客户端 22 秒、服务端模型请求 18 秒超时。
- 版本化提取与增量 prompt。输出严格允许字段、时间格式、数量上限、引用一致性校验，事件证据必须出现在原文。结构合法不代表语义绝对正确，用户仍需确认。
- 请求缓存按签名匿名用户、prompt 版本、描述及紧凑上下文 SHA-256 隔离；内存最多约 500 项、24 小时过期，不持久化原始生活描述。
- 匿名 HttpOnly 签名 Cookie、每用户每天默认 8 次、每 IP 每小时 60 次、同用户单并发。使用持久化预算账本；清 Cookie 可生成新身份，因此不是付费账号级强身份配额。
- 使用量记录输入/输出 tokens；只有显式配置 token 价格才估算成本。缓存和 IP 限流仅单进程有效，不是分布式基础设施。
- 同源浏览器写入检查；生产 Cookie Secure；静态文件限制在 dist；意向与预算文件以私有权限原子替换。私有持久卷和密钥管理由部署方配置。无账号、云端活动同步、数据库、多租户和支付 webhook。
- 意向邮箱是服务端个人资料，不进入公共统计；本机“清除数据”只清浏览器数据，不会删除服务器意向。尚无自助服务端退订/删除页面，部署前需要补充处理流程和隐私政策。
