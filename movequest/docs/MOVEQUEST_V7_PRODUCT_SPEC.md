# MoveQuest V7.0 · 产品规格

MoveQuest 帮学生和办公人群在每天已经发生的任务和间隙里找到能试一次的小活动。主流程为生活对话、确认线索、查看一到三条发现、记录自己的体验、把合适的时机种成习惯、回城镇看变化。

| 入口 | 用户能完成的事 |
| --- | --- |
| 我的世界 | 浏览和装饰城镇、查看地点与发现标记、查看尝试带来的街区变化 |
| 今日发现 | 对照原话、触发条件、时长、行动、安全条件和指南，试一次或记录跳过 |
| 习惯花园 | 把首次尝试挂到触发事件，记录重复、自主发起和便利度，开展短实验 |
| 探索图鉴 | 查看地点、街区解锁和发现背后的知识 |
| 我的生活 | 文字与语音输入，确认、修改或手录生活资料，管理行动、提醒和本机数据 |

基本发现、习惯与城镇皆使用现有免费功能。应用保留既有明确登记的意向入口。潜在付费假设包括更多主题、实验对比和个人报告，当前没有支付和已验证的购买需求。

本机事件最多保留 500 条，每条只有事件名、内部键和时间。和个人资料一样进入本机导出，演示分析独立，无后台分析上报。定义如下，以独立用户或装置去重时需要合法、可用的长期身份，目前产品没有跨设备身份。

| 衡量对象 | 口径 |
| --- | --- |
| 引导完成率 | 同一统计期内完成首次地点确认的使用者 ÷ 开始引导的使用者 |
| 机会接受率 | 点击试一次的机会曝光数 ÷ 机会曝光数，需同一轮曝光归因 |
| 确认行动率 | 已确认做过的尝试 ÷ 接受次数，按同一机会窗口归因 |
| 习惯重复率 | 至少在两个本地日期确认同一习惯的计划 ÷ 已创建计划 |
| 主动发起率 | 自报主动发起的完成 ÷ 习惯完成数 |
| D1 / D7 | 首次使用后第 1 / 7 个本地日期有实际事件的使用者 ÷ 当日新使用者 |
| 城镇参与 | 有地点探索或街区解锁的使用者 ÷ 同期活跃使用者 |
| 付费兴趣 | 有显式意向登记的使用者 ÷ 实际看到意向入口的使用者 |

这些是分析口径。当前本机日志用于验证流程，曝光到行动没有完整归因，未产出留存或商业数据。
