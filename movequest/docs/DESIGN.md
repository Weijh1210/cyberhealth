# MoveQuest 设计与评审记录

## 方向

使用 `design-taste-frontend` 的 app-screen 流程，抽取方向为 **Editorial greeting**，seed **1127530367**，没有重抽。按任务书保留鼠尾草绿、奶油底色与系统字体；桌面为 230px 安静侧栏与最大 1100px 内容列，16px 主间距。手机改为五项底部导航。

产品识别来自“微动留下生长”：自绘小菜圃把 XP 变成可见的植物阶段。用有层次的实色，避免竞技排名、断签惩罚、植物枯萎、复杂货币商店与无来源的成果数字。

## 产品对象与屏幕问题

- 用户对象：身份、名字、常见场景、1–3 分钟偏好与 0/30/60 分钟提醒；新用户所有活动与 XP 从 0 开始。
- 任务对象：校园、办公室、居家、户外，各 3 项；计时或三步引导；每次完成必须由用户确认。
- 成长对象：20 XP 活动、5 XP 学习、五阶段花园与八项成就；从记录推导，数字一致。
- 发现对象：自己的情境与小行动；记录发现与实际活动分开。
- 机构对象：固定合成参与者、开始/完成明细、学习状态、场景与本地草稿。
- Onboarding：什么建议适合我的日常？
- Home：此刻可以从哪个小行动开始，花园长到哪里了？
- Explore：我的场景和时间里，有什么可做？
- Quest：现在怎么做、是否可以暂停、何时确认？
- Learn：我从这次活动学到了什么？
- Progress：我的活动、探索和主动发现留下了什么？
- Institution：所选 Demo 活动中，参与、完成与学习各是什么情况？

## 可访问性与动效

正文以 14–16px 为主，次级标签 12px，脚注最小 11px；对比度问题经 axe 发现后加深次级文字颜色。按钮至少 44px 高，焦点可见，提供语义标签与键盘操作；植物只在阶段改变时短暂生长，减少动画偏好下关闭。

手机学习列表采用容器内横向滚动，Grid 子项设置 `min-width:0`，解决了窄屏页面被撑宽、底部导航点击偏移的问题。溢出验收使用文档 clientWidth，而非会随移动布局扩大的 innerWidth。

## 浏览器检查

实际检查 1440×900 桌面、390×844 手机；同时检查 320px 与 768px 布局。E2E 对八个主要路由运行 WCAG 2 A/AA 自动检查；这不等于完整人工无障碍认证。

技能 inspector 对 Onboarding 和实际机构 Dashboard 在 1440 / 768 / 390 宽度渲染检查。修复了小于 11px 的可见文字，最后机构检查 **0 FAIL、4 WARN**。保留警告的理由：

- Cream：奶油底色为用户明确指定的 Cozy Game 方向。
- Tiny text share：较小文字用于元信息、日期、指标口径与 Demo 标签，核心活动和操作文案保持 14px 以上，实际 axe 对比度通过。
- Panel void：两个机构模块配对同高，在只有一个草稿的空状态保留少量余量，不补造活动或无意义数据。
- No-data-hue：图表实际用绿色 CSS 柱和进度条呈现；该探针没有识别这些 CSS 图形的颜色，截图已人工核对。

已查看桌面、平板与手机实际截图。主要页面截图由生产构建 E2E 生成在 `docs/screenshots/`。图中姓名及活动均是隔离测试数据，展示成果不代表用户真实运动或机构试点。

## 3.0 生活城镇扩展

沿用既有绿、米白和字体系统，主工作面扩展为可操作的生活城镇。用户参考图决定等距微缩方向；原创实体面、房顶、窗户、街边树、长椅、花丛与地块取代单一花园作为首页主体。没有复制参考游戏资产。桌面城镇与机会栏并排，手机先地图后机会，再时间轴；原成长区折叠保留。场景、空闲与时区在地图前直接可操作。

地图提供鼠标/触控/键盘操作，机会标记轻浮动，减少动画偏好时关闭。装饰独立于真实日程。待审核动作没有开始入口，空推荐不补造内容，未连接 AI 时明确手动录入，Plus 页面明确意向而非购买。

实际查看双端 v3-town 截图，新增四页通过双端 axe 和溢出检查。画面是清晰的矢量微缩几何，不是参考图级的完整 3D 材质、室内剖面或角色世界。技能上下文加载器因沙箱缓存权限未运行，改读项目设计与 craft-floor 指南；本次没有声称运行或通过其 inspector。

## V4 世界优先的演示表面

保留已有色彩与字体身份，首页主工作面改为宽幅城镇，机会信息在桌面地图侧边浮层、手机底部可收起面板；成长／知识下移折叠。用户参考方向决定建筑几何、低饱和绿化和一致的等距视角。本次新增学校独立结构、花园空地、中央景观、道路入口、树叶／装饰交通动画及日光／暮色两主题，保持素材风格统一。

六种装饰及撤销是实际状态操作；模拟情境、待审核动作、休息统计与 AI 不可用状态都有明确文案。手机验收发现并修复了机会按钮挡住放置装饰，以及横向滚动区域缺少可访问焦点的问题。演示人物名称及生活数据均为样例，未制造真实健康进展。

最终截图和验收结果见 V4 报告。地图仍为原创矢量实体几何，未宣称达到参考图的高精度材质或实体手机帧率标准。没有运行不可用的设计技能 inspector；使用真实浏览器截图、交互与 axe 检查。
